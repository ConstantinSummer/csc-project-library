# CSC Project Catalogue

The central catalogue of complete educational applications from **Computer Science Center (CSC)**. Education website: [https://csc.gr](https://csc.gr). Maintainer: **Konstantinos Zitis**.

All areas below are **Planned**. These rows reserve catalogue areas; they do not announce specific applications or existing repositories. Project names, levels and release links will be assigned when projects are defined. A dash means not yet assigned.

## Catalogue conventions

Each future application entry records its name, learning focus, primary level (Foundation / Intermediate / Advanced), status, repository link and stable release link. Levels are defined in the [library overview](../README.md#learning-levels).

- **Planned**: proposed work without a verified published teaching baseline.
- **Available**: a published release meets the [CSC project standard](../docs/PROJECT_STANDARD.md).
- **Archived**: retained for reference and no longer maintained; document limitations in the project repository.

Group each application under its primary area and mention secondary technologies in its learning focus. Replace an area's placeholder with concrete entries as projects are defined. Repository names follow `csc-<technology>-<project-name>`; do not add speculative repository or release links.
