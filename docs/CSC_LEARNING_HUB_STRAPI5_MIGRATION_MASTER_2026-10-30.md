## Official Strapi migration contract (verified Oct 2026)
- As of 2026-10-30 latest stable: **5.60.0** (2026-10-28): https://github.com/strapi/strapi/releases
- Official steps https://docs.strapi.io/cms/migration/v4-to-v5/step-by-step : upgrade v4 to latest v4 patch in **isolated clone**, DB+code backup, plugin audit, `npx @strapi/upgrade major`, inspect codemod `__TODO__`, then manual updates/contract tests.
- V5 REST data flattened: `data.title` replaces `data.attributes.title`; V5 uses `documentId` on content routes/relations. Header `Strapi-Response-Format: v4` **temporarily** restores wrapper, but does not eliminate ID migration: https://docs.strapi.io/cms/migration/v4-to-v5/breaking-changes/new-response-format
- Server `entityService` to `strapi.documents`; lifecycle hooks may be commented out by codemods and require conversion to Document Service middlewares. Verify publish/draft status semantics, route signatures, populated relations, email/S3/R2 providers.
- Exception: Strapi Upload and Users & Permissions may not follow the same response shape; media IDs in related upload endpoints may remain numeric. Test these separately: https://docs.strapi.io/cms/api/rest
