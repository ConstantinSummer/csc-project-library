# CSC Learning Hub — Public Concept Overview

> This is a **public summary only**. The detailed migration plan, technical implementation status, deployment proofs and operational history are maintained in the CSC owner's private GitHub workspace.

## Vision
CSC Learning Hub is planned as a mobile-first education portal with structured lessons, assignments, progress tracking, and optionally video learning and AI-assisted study.

## Direction as of 2026-10-30
- Keep the existing `csc.gr` public educational pages and their SEO.
- Study a shared Flutter/Dart student experience for Web, Android and iOS; evaluate the older unfinished prototype first.
- Modernize the educational content backend through staged testing, protecting existing web content and automated publication.
- Keep student access permissions, classroom data, and private materials secure.
- No new public Learning Hub production release is claimed.

Technical reports, code migration gates, security findings, backups, credentials, and project-management checkpoints are **not** included in this publicly visible repository.
